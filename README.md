# Smart-Campus-AIoT-Solution 
> **基于多源传感器融合与边缘计算的高校教学楼智能化方案**

## 01. 项目背景 (Project Background)
本项目针对高校教学楼在暖通环境调节与设施运维中的真实痛点（如：空调能耗空耗、报修响应滞后）进行设计。通过构建以 **AIoT 数字化感知底座** 为核心的系统，实现从“被动响应”向“主动感知、智能联动”的数字化转型。

## 02. 系统架构 (System Architecture)
方案采用工业级标准的三层架构，确保系统在复杂教学环境下的高可靠性：

* **感知层 (Perception Layer)**: 部署多合一环境传感器（温、湿、CO2）与毫米波雷达，实现空间数据的数字化精准采样。
* **网络层 (Network Layer)**: 采用 **RS485 总线** 配合 **Modbus-RTU** 协议，确保数据传输的抗干扰性与稳定性。
* **应用层 (Application Layer)**: 边缘网关运行 Python 联动逻辑，并对接轻量化 Web 报修端。

## 03. 核心技术亮点 (Technical Highlights)

### 3.1 多模态感知与空调前馈联动
不同于传统的恒温控制，本项目引入了 **CO2 浓度感知** 作为人员密度的前馈变量：
* **逻辑控制**: 当检测到 CO2 浓度 > 1000ppm 时，系统自动联动开启新风系统。
* **温度补偿**: 针对新风引入带来的热负荷，系统自动调优空调出风温度，保障室内 PMV（热舒适度）恒定。

### 3.2 敏捷运维：一物一码轻量化报修
* **数字化资产**: 教学设施（白板、投影）通过唯一二维码实现空间绑定。
* **敏捷交互**: 基于 Web 的扫码报修流，实现“扫码-选故障-秒级分发”的极简闭环。
